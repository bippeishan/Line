01

产品定位与用户

将零散的钩织工具、图解、材料信息和社群互动整合为一款长期可使用的创作助手。它不只解决“怎么算”，也帮助用户完成“怎么钩、钩到哪、还缺什么、如何分享或售卖”。

核心用户

用户类型典型需求产品机会
新手学针法、看懂图解、避免数错分步教程、符号词典、行数提醒与错误排查
爱好者管理多个作品、调整尺寸与配色项目工作台、计算器、材料库存和图解标注
图解作者制作、发布和售卖规范图解图解编辑器、PDF 导出、水印、付费与数据统计
社群主理人沉淀内容、带动打卡与转化挑战活动、作品库、会员内容和私域工具

产品原则

高频优先先覆盖每次开工、持续钩织和停工恢复时都会出现的问题。
数据沉淀项目、线材、图解和成品记录应持续留在用户账户中。
创作友好为图解作者保留清晰的署名、授权、水印与收入能力。
工具可信计算结果必须可解释、可复核，并提供异常提示。
02

功能全景

采用“工具层 → 内容与学习层 → 社区与交易层”的递进结构：工具建立使用习惯，内容形成差异化，社区和交易放大留存与收入。

A · MVP FOCUS

基础工具层

钩织计算器：环形起针、加针减针、行数、密度、尺寸与用线量估算。

项目进度：当前行数、步骤勾选、断点笔记、计时、语音/快捷计数。

材料与库存：线材批次、余量、针号、辅料、缺料提醒与作品成本。

B · DIFFERENTIATION

图解与学习层

图解阅读器：导入 PDF/图片，放大、标注、行高亮、术语对照与 OCR。

图解生成器：文字针法转标准图表，可视化编辑，导出高清 PDF/长图。

AI 助手：逐行解释、尺寸改版、材料替代、结构建议与错误排查。

C · ECOSYSTEM

社区与商业层

图解库：发布、试读、购买、更新通知、授权分级和作者主页。

作品社区：打卡、同款作品、求助帖、主题圈与阶段挑战。

创作者经营：定价、优惠券、订单与收入统计、会员内容和防盗水印。

03

关键功能清单

3.1 钩织计算器

  • 起针与形状：魔法环、圆形、椭圆形、平片、底部与常见立体结构的起针及每行针数。
  • 加减针与尺寸：根据目标尺寸、密度和现有图解，推算加减针节奏、行数和成品尺寸。
  • 材料估算：按线材克重、长度、针号和目标大小估算用线量，支持余线预警。
  • 单位与参数：厘米/英寸、线重、针号换算，并保存用户常用密度样本。

3.2 项目与材料工作台

  • 项目卡片：记录名称、封面、关联图解、目标尺寸、针号、线材、当前状态与完成时间。
  • 进度执行：行数计数、分段计时、步骤清单、关键行提醒、断点和照片笔记。
  • 库存联动：从库存挑选线材；项目消耗自动扣减；显示批次、剩余量和补货提醒。
  • 成本核算：汇总线材、辅料和工时，服务于接单定价与成品售卖。

3.3 图解、AI 与内容

  • 图解阅读：支持 PDF、图片与长图；局部标记、行高亮、符号词典和术语翻译。
  • 图解创作：文字针法转图表，圆形/片状/玩偶模板，拖放编辑、配色与编号。
  • 智能问答：解释“这一行怎么钩”、诊断针数不一致、建议尺寸和线材替代方案。
  • 成品与教学：作品展示、短视频针法库、入门路径、挑战计划与课程。

3.4 我的线材、我的工具与配色推荐

  • 我的线材：建立个人线材库，支持照片、名称、品牌、颜色、材质、粗细与股数录入；可按属性检索、筛选和关联项目。后续根据图解的线重、材质、颜色与用量要求，从用户自有线材中推荐合适候选，并说明匹配依据与差异。
  • 我的工具：建立个人工具库，支持照片、名称、类型与粗细录入；项目可关联已拥有的钩针、棒针及辅助工具，减少重复购置和针号遗漏。
  • 配色推荐：提供独立配色推荐页，按同色系、邻近色、互补色、三角色等色彩关系，为用户展示每套 3 种颜色搭配；支持以已有线材颜色为起点筛选可落地的方案。
04

推荐路线图

首发聚焦“项目进度 + 计算器 + 图解阅读”。这三项既有明确痛点和较高使用频率，也能够积累后续图解生成、推荐和交易所需的数据。
阶段交付重点目标
阶段一：MVP行数计数、钩织计算、项目管理、我的线材、我的工具验证高频使用与首批留存
阶段二：效率图解导入标注、符号词典、配色推荐、PDF 导出、作品打卡建立个人作品和图解资产
阶段三：差异化文字转图解、AI 图解问答、图解与自有线材智能匹配、作者发布与售卖形成专业能力与初步变现
阶段四：生态社区、课程、材料推荐、创作者经营工具扩大内容供给和交易规模
05

商业化设计

  • 会员订阅：高级计算、云同步、无水印导出、扩展项目管理和 AI 使用额度。
  • 单次付费：高级图解、导出包、专业模板、尺寸改版和定制服务。
  • 创作者交易：图解售卖、课程、材料包和商用授权；平台收取服务费。
  • 材料合作：根据项目材料清单提供线材、钩针与辅料推荐，并获得联盟分成。
06

下一步建议

  1. 选择一个明确的首发人群，例如“钩织玩偶爱好者”或“新手钩织入门用户”，避免首期覆盖全部品类。
  2. 用 10–20 位目标用户访谈验证：最常数错的场景、最常用的图解格式，以及愿意付费的功能。
  3. 先制作可点击原型，重点测试“创建项目 → 导入图解 → 计数/提醒 → 完成打卡”的完整闭环。
  4. 为计算规则和图解符号建立可配置的基础数据模型，为后续 AI 与创作者平台预留接口。
